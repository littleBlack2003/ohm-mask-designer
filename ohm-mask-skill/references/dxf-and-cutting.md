# DXF 与激光切割说明

## 输出约定

- 格式: **DXF R12 (AC1009)**, 文本, UTF-8 + LF。兼容 AutoCAD 2026 与主流激光 CAM。
- 单位: mm(`$MEASUREMENT=1`, `$INSUNITS=4`)。导入后仍应确认一次单位。
- 独立圆孔 = `CIRCLE`; 槽、方孔、异形及合并轮廓 = 闭合 `POLYLINE`(圆弧按折线离散)。无缺口的圆形定位开口仍为 `CIRCLE`。
- 把手与主体仅输出一条外边界; 取片缺口与定位开口仅输出合并边界, 不保留连接横线、相交直线或重复圆。合并中的圆弧弦高误差默认 ≤ 0.001 mm, 可用 `curve_tolerance_mm` 调整。
- 非 ASCII 文字在 R12 里用 AutoCAD `\U+XXXX` 转义, 打开可正常显示。
- **不输出厚度/材料标注**: 图纸只定形状与尺寸, 厚度与材质下单时选择。

## 图层与颜色

**单件图 / 订单图**(掩模片、骨架、遮光 mask):

| 图层 | 颜色 | 内容 | 切割 |
|------|------|------|------|
| `OUTLINE` | 红 1 | 板外形 | 是, 切穿 |
| `HOLES` | 绿 3 | 功能孔 | 是 |
| `WINDOW` | 蓝 5 | 骨架定位开口 | 是 |
| `PICK` | 黄 2 | 旧版独立取片缺口图层; 新版缺口合并至 `WINDOW` | 新版不输出 |
| `TOOLING` | 青 4 | 安装孔 | 是 |
| `REFERENCE` | 品红 6 | 基片/镀银区参考 | 否 |
| `ITO_EFFECTIVE` | 品红 6 | ITO有效区域边界 | 否 |
| `LASER_MARK` | 橙 30 | 激光打标文字的闭合矢量字形 | 打标, 不切穿 |
| `NOTES` | 灰 8 | 文字标注 | 否 |

**装配图**(蒸镀对片): 各部件用前缀区分, 便于分别提取:

| 图层 | 内容 | 切割 |
|------|------|------|
| `FOIL_OUTLINE` / `FOIL_HOLES` / `FOIL_TOOLING` | 0.1mm 掩模片 | 是 |
| `FRAME_OUTLINE` / `FRAME_WINDOW` / `FRAME_TOOLING` | 2mm 骨架(取片缺口含在定位开口边界内) | 是 |
| `SUB_REFERENCE` | 基片外形(看对位) | 否 |

激光机台按图层选加工路径; **不要把 `NOTES` / `REFERENCE` / `SUB_REFERENCE` / `ITO_EFFECTIVE` 当切割层**。DXF参考图层仍是几何实体, 在CAM中须明确排除这些图层。

## 蒸镀对片的下单

- 装配图只用于核对对位(掩模片轮廓、骨架定位开口、基片三者同心叠加)。
- 掩模片订单: 用 `<名>_掩模片.dxf`; 骨架订单: 用 `<名>_骨架.dxf`。
- **安装孔为可选项**, 未要求时不添加。需要销钉对位时, 两片可用同一组安装孔(`frame_holes` 参数保持一致)。
- 骨架定位开口比基片每边大 0.1mm(旷量 0.2 总差), 基片放入后留 0.1mm/边 间隙。

## 在 AutoCAD 中检查

1. 打开 `.dxf`(或 `DXFIN`)。
2. 图层管理器确认图层齐全、颜色正确。
3. `ZOOM` → `Extents`, 量外形/定位开口尺寸是否等于规格。
4. 数孔数, 与报告核对; `LIST` 抽检关键孔坐标。

## 送激光切割前

- **割缝补偿(kerf)**: 本 DXF 是设计名义尺寸, 不含补偿。由机台按材料/厚度在排版时补, 或明确告知加工方"按图形切割"。
- **引线/进刀**: 在 CAM 里加引入引出, 避免穿孔点落在成品区。
- **材料方向与张紧**: 确认轧制方向、张紧框夹持区、安装孔位置。
- **尖角/细长筋**: 巡检最细的筋和最小孔, 必要时放宽。
- **校验结果**: 真实轮廓越界或加工路径相交/重叠/相切时停止输出, 退出码 2。旧图不会删除, 不应误当作失败运行的新结果。筋宽警告需处理后再下单。
- **毛刺/热影响区**: 薄片边缘毛刺建议去毛刺, 面向基片一侧避免划伤。

## 常见坑

- 把 `NOTES` / `REFERENCE` 层一起切了 -> 多切出文字或参考轮廓。
- 旷量填成"单边值" -> 定位开口偏大。记住 `clearance_mm` 是**边长总差**, 单边自动减半。
- 掩模片孔越出定位开口 -> 报告警告 `[警告] ... 超出允许边界`, 检查阵列范围或基片尺寸。
- 遮光 mask 通光孔压到镀银区边缘 -> 检查 `silvered` 与 `aperture_inset_mm`。
- 单位搞错(寸 vs mm) -> 导入后量外形确认。
