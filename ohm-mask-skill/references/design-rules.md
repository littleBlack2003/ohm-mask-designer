# 镀膜遮挡掩模板设计要点

> 下列数值为通用工程经验区间, **不是绝对标准**。不同镀膜机、入射角、靶材与工艺窗口差异很大。
> 首次做某类产品时, 用试镀片实测标定, 并把本厂验证过的数据回填到本文档。

## 0. 本厂两类掩模板

### 蒸镀掩模板(两片不锈钢)

- **0.1mm 掩模片**: 带开孔图形的薄片, 是真正的掩模面。太薄、单独无法拿取, 靠骨架支撑。
- **2mm 骨架(母板)**: 厚片开窗做支撑。**定位开口的用途是把待蒸镀的玻璃片嵌进去定位**(型腔),
  定位开口比基片大一圈(旷量), 让基片顺利放入又不晃动。
- **批量母板**: 一块母板阵列多个定位开口, 一次装多片。**实盘他们的母板**: 9×9 = **81 个 7.6×7.6 定位开口**,
  中心距 10mm(7.6 孔 + 2.4 筋), 对应 **7.4mm 玻璃**(旷量 0.2); 板外形约 95×97.5, 顶部带 25×17 凸台。
  这在 spec 里就是 `skeleton.windows` 的 `array` 阵列。
- **把手**: 母板外形上凸出的一块方台(本厂称"把手"), **供手捏握着搬取整块板**, 不是工艺孔。
  实盘母板把手 50×34, 位于主体一条边的中央。外形可用 `outline` 的 `polygon` 直接画出。
- **取片缺口**: 在定位开口边上或角上开的圆弧缺口, 与定位开口合并, **方便用镊子伸进去把
  蒸镀好的玻璃片取出来**。没有它, 平嵌在定位开口里的薄片很难夹起。每个定位开口至少一个。
  **孔径与缺口位置按具体产品分析**(取决于镊子尺寸、片子大小、定位开口位置), 不套固定值。
- **旷量**: 骨架定位开口与基片的**边长总差**, 通常 0.2mm(单边 0.1mm)。给基片留装配余量,
  又避免缝隙大到漏镀。
- 掩模片与骨架**同轮廓**(掩模片外形默认 = 骨架外形), 通过焊接/铆接/销钉固定成一体。
- **安装孔可选**; 需要用安装孔对位或固定时, 两片可采用同一组。装配图核对掩模片轮廓、骨架定位开口、基片三者同心。
- 组合后总厚 0.1+2 = 2.1mm(组装间隙另计), 参与厚径比判断时按实际叠层算。

### 测试遮光 mask(单件)

- 外形**和基片一样大**, 方便贴合与对位。
- **通光孔比镀银区小一圈**(单边内缩, 如 0.3mm), 目的:
  - 遮挡镀银区边缘, 只让中心有效区通光, 避免边缘效应/溢镀影响测试;
  - 保证不会把镀银区外的光放进探测器。
- 通光孔常为多孔图案(阵列), 用于多点/分区测试; 每个孔的边界都在镀银区内缩区内。
- GUI从蒸镀项目自动派生测试mask时，以“活性区域开口 ∩ ITO有效区域”为母轮廓，通光孔默认取80% 边长，宽、高吸附到0.1 mm，并必须严格位于母轮廓内。

## 1. 阴影效应(shadowing)与厚径比

PVD 是直线/近直线沉积, 掩模板有厚度 `t`, 孔有直径 `d`。当镀料以入射角 θ(相对孔轴)入射时,
孔壁会遮挡部分区域, 实际镀膜区沿入射方向偏移并收缩。

- 用 `t/d`(厚径比)粗判: `t/d` 越小, 阴影越小。
- 垂直入射(θ≈0)且 `t/d ≤ 0.5` 时阴影通常可忽略; `t/d ≥ 1` 时务必实测定标。
- 入射角越大, 需要的孔径余量越大, 或改用更薄的材料。
- 脚本报告中的 `t/dmin` 只是提示, 判定仍需结合入射角。

## 2. 孔径补偿

由于阴影、绕镀、边缘扩散, 掩模板上的**图形孔径**与基片上**成品区尺寸**通常不相等:

- 图形孔径可略小于目标尺寸(正补偿), 具体量按工艺标定, 常以 µm~几十 µm 计。
- 本 skill 输出的 DXF 是**图形名义尺寸**。如果客户给的是成品尺寸, 先换算成图形尺寸再填 spec,
  并在报告中记录补偿依据。
- 激光割缝(kerf)是另一项, 由机台在 CAM 里补偿, 不要在这里减。

## 3. 筋宽 / 机械强度

- 孔与孔之间、孔与外框之间的剩余材料叫筋(web)或腹板。
- 太窄会在张紧、装夹、镀膜升温时变形甚至断裂。
- 经验下限: 筋宽 ≥ max(0.2~0.3 mm, 板厚)。薄片(≤0.3 mm)取下限, 厚片适当放大。
- 大面积高开孔率区域必须留加强筋(把阵列 `skip` 出十字/井字筋)。
- 脚本用 `min_web_mm` 检查所有加工轮廓之间以及到外框的最短距离(含合并定位开口缺口、异形孔和安装孔), 圆形距离用解析半径。报告取曲线离散误差的保守下界; 仍需结合实际厚度、装夹与热变形评估强度。

## 4. 材料选择

| 材料 | 特点 | 适用 |
|------|------|------|
| SUS304/316 | 易加工、成本低、有一定热膨胀 | 常规、小批量 |
| Mo(钼) | 耐高温、寿命长 | 高温/长寿命工艺 |
| Ni(镍) | 薄、平整 | 精细小孔 |
| Invar(因瓦) | 低热膨胀 | 高精度对位、大尺寸 |

选材还受工艺温度、靶材洁净度、是否磁性等约束。

## 5. 定位与装夹

- 四角/对角安装孔(`frame_holes`)用于销钉定位, 保证与基片对位。
- 大片、极薄片需张紧框(张网)固定, 掩模板外形四周要留工艺边供夹持。
- 留边缘余量 `edge_margin_mm`, 避免孔切到板边导致掉边。

## 6. 热变形

- 镀膜升温会使薄片膨胀, 改变孔位。大面积高精度件考虑 Invar 或与基片匹配的材料。
- 多个图形分区时可做分区定位, 减少累积误差。
