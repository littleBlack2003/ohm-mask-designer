# 掩模板图纸制作

## 统一术语

| 称呼 | 含义 | 规格字段 |
|------|------|----------|
| 定位开口 | 骨架上容纳并定位基片的开口 | `skeleton.windows` |
| 取片缺口 | 定位开口边上或角上供镊子取片的缺口 | `skeleton.pick_hole` |
| 安装孔 | 可选的安装、对位或固定用独立孔 | `frame_holes` |
| 图案阵列 | 单格图案的重复排列, 用列数×行数、中心距及起始位置描述 | `nx` / `ny` / `pitch_x` / `pitch_y` / `origin` |

文档、报告、图纸说明统一使用上述称呼。`pitch_x/pitch_y` 表示图案阵列的 X/Y 中心距, 单位 mm。
JSON 字段名及 DXF 图层名沿用现有接口, 如 `windows`、`pick_hole`、`frame_holes`、`WINDOW`、`TOOLING`。

**目的**: 简化掩模板图纸的制作。用户只需描述**单个片子上的图案**, 其余全部由 AI 完成:
把所有参数问清楚 → 阵列复制图案 → 画边框/把手/取片缺口 → 出切割 DXF(+填充配色)。

核心工具 [scripts/make_mask.py](./scripts/make_mask.py): 使用 Shapely 做几何布尔运算, 不依赖 ezdxf/AutoCAD,
输出 DXF R12 (AC1009), AutoCAD 2026 与主流激光 CAM 均可读。
首次运行前检查依赖, 缺少时在 skill 目录执行 `python -m pip install -r requirements.txt`。
填写规格前按需阅读 [references/spec-format.md](./references/spec-format.md)。

## 工作方式(重要)

1. **用户只给单格图案**(孔径、形状、条数、间距等)。不要要求用户画整片阵列。
2. **AI 主动询问必要参数**, 缺项就追问, 不要臆造; 用户已知的跳过。安装孔为可选项, 未要求时不添加, 不因缺少安装孔阻塞生成。
3. AI 选出合适模板(spec), 把参数填进去, 生成并校验, 交付。
4. 阵列、边框、把手、取片缺口、装配图、填充配色 —— 都由工具算, 不靠用户手画。

### 要问的参数清单

| 类别 | 参数 | 默认/说明 |
|------|------|-----------|
| 基片 | 尺寸、方形/圆形 | 如 15×15 |
| 旷量 | `clearance_mm` | 边长总差, 默认 0.2(单边 0.1) → 定位开口 = 基片 + 旷量 |
| 图案阵列 | 列数×行数 `nx×ny`、中心距 `pitch_x/pitch_y`、起始位置 | 骨架定位开口与单格图案共用同一阵列 |
| 单格图案 | 开口形状(圆/方/长槽/异形)、尺寸、条数、格内间距 | ← 用户主要提供这项 |
| 边框 | 骨架外框尺寸、是否圆角 | 直接给外形尺寸 |
| 把手 | 宽×高、在哪条边 | 供手握取; 掩模片沿用骨架外形时两片均带把手 |
| 取片缺口 | 圆径、放在哪条边或哪个角、每定位开口几个 | 可放边上或角上, 供镊子取片; 尺寸按具体产品定 |
| 安装孔（可选） | 需要时提供孔径、位置或角位内缩量 | 未要求时不添加; 需要两片对位时可用同一组 |
| 产出 | 要装配图/掩模片/骨架哪几张、要不要填色 | 默认蒸镀出 3 张 |

> 厚度/材料**不写进图纸**, 下单时选; 规格里也没有厚度字段。

## 两类掩模板

### 1. 蒸镀掩模板 (`kind: "evaporation"`) —— 两片不锈钢

| 部件 | 厚度 | 作用 |
|------|------|------|
| 掩模片 | 0.1mm | 带图案的薄片, 真正掩模面; 薄 → 阴影效应小 |
| 骨架(母板) | 2mm | 支撑定位; 定位开口嵌玻璃片、把手握着搬、取片缺口用镊子取片 |

- **定位开口**: 把待镀玻璃片嵌进去定位; 定位开口 = 基片 + 旷量(15.0 → 15.2)。
- 方形基片的定位开口默认保持直角; 旷量不自动生成圆角。只有明确指定基片圆角时才生成对应圆角, 取片缺口按独立参数处理。
- **整片 = 单格图案 × 图案阵列**(中心距/原点共用), 所以只需定义一格。
- **把手**: 骨架外形边上凸出的方台(`skeleton.handle`), 供手握取。
- **取片缺口**: 可设在定位开口的边上或角上(`skeleton.pick_hole`), 镊子伸入取片。边上用 `edge`, 角上用 `corner`。
- **安装孔（可选）**: 需要时才设置 `frame_holes`; 不设置即可生成无安装孔图纸。
- **一次出 3 个 DXF**: `<名>_装配图` / `<名>_掩模片` / `<名>_骨架`。

```json
{
  "kind": "evaporation",
  "name": "EV-15-9x9",
  "clearance_mm": 0.2,
  "substrate": { "type": "rect", "width": 15, "height": 15 },
  "skeleton": {
    "outline": { "type": "rect", "width": 190, "height": 195, "corner_radius": 2 },
    "windows": { "type": "array", "pitch_x": 20, "pitch_y": 20, "nx": 9, "ny": 9, "origin": [-80,-80] },
    "handle":     { "width": 50, "height": 34, "edge": "top" },
    "pick_hole":  { "diameter": 7.6, "edge": "top" }
  },
  "foil": {
    "per_window": true,
    "cell": [ { "type": "rect_array", "width": 2.4, "height": 14, "pitch_x": 3.8, "pitch_y": 0,
                "nx": 2, "ny": 1, "origin": [-1.9, 0] } ]
  }
}
```

`foil.cell` = 单格图案(等价 `foil.features`), 坐标相对**定位开口中心**; `per_window: true` 时在 81 个定位开口各复制一份。

### 2. 测试遮光 mask (`kind: "light_block"`) —— 单件

- 外形**和基片一样大**; 通光孔(多孔图案)比片子**镀银区**小一圈(`silvered` + `aperture_inset_mm`)。
- 同样只给单格/单孔图案, 由 AI 阵列。

### 3. 通用单件 (`kind: "single"`, 默认)

单件外形 + 图案, 无骨架/把手。

## 铁律

1. **用户只给单格图案, 参数由 AI 问全**。不要臆造尺寸; 缺项追问。
2. **厚度/材料不写进图纸**(下单时选)。
3. **单位 mm, 切割轮廓闭合**; 独立圆孔 `CIRCLE`, 其余闭合 `POLYLINE`; 把手与外框合并, 取片缺口与定位开口合并后只输出最终边界。文字/参考放 `NOTES`/`REFERENCE`。
4. **必须看校验报告**: 真实轮廓越界、相交/重叠、最小筋宽、开孔占比。`[错误]` 阻止写出 DXF 并返回退出码 2; `[警告]` 需结合工艺处理, 不当作无条件可下单。失败时输出目录的旧图不是本次结果。
5. **DXF 是设计名义尺寸, 不含割缝补偿**(kerf 由机台按材料厚度补)。

## 图层与配色

**订单图**(掩模片、骨架): `OUTLINE`(红 外形) / `HOLES`(绿 功能孔) / `WINDOW`(蓝 定位开口) /
`TOOLING`(青 安装孔) / `REFERENCE`(品红 参考) / `NOTES`(灰 文字)。取片缺口已包含在 `WINDOW` 轮廓中, 不另输出完整 `PICK` 圆。

**装配图**: 部件前缀 `FOIL_*` / `FRAME_*` / `SUB_REFERENCE`。
可选的 **ITO有效区域** 使用独立 `ITO_EFFECTIVE` 品红参考图层, 由 `ito_effective.features` 定义并按每格复制; 不用于切割。GUI可切换图层绘制和调整该区域。
可选的 **激光打标文字** 由 `laser_marking` 定义, 在全板外框/把手上定位, 可选骨架、掩模片或两片。使用本机微软雅黑字体与 Matplotlib 转为 `LASER_MARK` 橙色矢量字形; 不参与切割轮廓统计。GUI支持内容、字高、角度和位置编辑; 切割版排除文字, 独立打标版仅含字形。
GUI另提供开孔数统计及有效面积不确定度计算：只计算标记为活性区域的开口，公共电极和未标记开口不计算；有效面积为活性区域开口与ITO区域并集的交集。默认图案尺寸公差±0.01 mm（矩形分布，可修改），可独立输入ITO尺寸及相对定位误差，逐活性区域输出名义面积、解析标准不确定度u、U=2u及计算说明，并导出CSV。生成加工包时以同一交集作为活性有效区域，将通光孔默认缩小到80% 边长并吸附到0.1 mm，然后生成外形默认同基板的测试遮光mask；公共电极不形成通光孔。参数以 `uncertainty_settings` 和 `test_mask` 保存，不影响蒸镀掩模轮廓。计算假设与适用范围见 [有效面积计算说明](../图案开口设计器/有效面积计算说明.md)。
浏览器工作台支持蒸镀总成的新建、打开、复制另存、完整项目JSON导入，以及基片、骨架、图案阵列、把手、取片缺口和可选安装孔设置。项目草稿与输出目录相互隔离；“生成加工文件”统一输出切割/打标/参考DXF、SVG、CSV、报告和本次加工ZIP。便携版内置计算环境，界面继续使用浏览器，操作见 [使用说明](../图案开口设计器/使用说明.md)。

**图纸填充配色**(用 AutoCAD 演示/出图时):
- **淡蓝** RGB(173,216,230) = **2mm 板实体区域**(外框挖定位开口)
- **淡黄** RGB(255,255,153) = **0.1mm 板实体区域**
- **粉** RGB(255,192,203) = **0.1mm镂空 ∩ 2mm镂空**(叠加图镂空 = 定位开口内未被掩模实体盖住 = 定位开口环 + 开口)

## 标准工作流

1. 判断类型(蒸镀对片 / 测试遮光 / 通用单件)。
2. 按"参数清单"向用户索取参数。
3. 复制模板改参数: 单格蒸镀 [cell_to_array.json](./examples/cell_to_array.json)、
   单片 [evaporation_pair.json](./examples/evaporation_pair.json)、批量母板 [evaporation_batch.json](./examples/evaporation_batch.json)、
   测试遮光 [light_block.json](./examples/light_block.json)、通用单件 [basic_array.json](./examples/basic_array.json)。
   角部取片缺口且无安装孔的示例见 [corner_pick.json](./examples/corner_pick.json)。
4. 生成并校验:
   ```powershell
   python "scripts\make_mask.py" "我的掩模板.json" --outdir "输出"
   ```
   逐项确认报告(错误/警告、开孔占比、筋宽)。圆形与异形按真实边界校验; 开孔占比含定位开口、取片缺口与安装孔, 重叠面积不重复统计。筋宽包含加工轮廓间与加工轮廓到外框的最短距离。
5. 需要演示/出图时, 在 AutoCAD 里按配色规则加填充。

## 环境事实

- 本机 Python 3.14、Shapely 2.2、AutoCAD 2026; 无 ezdxf, 本工具也不需要。其他机器安装 [requirements.txt](./requirements.txt)。
- 合并缺口中的圆弧转为折线, `curve_tolerance_mm` 控制这些圆弧的最大弦高误差(默认 0.001 mm)。独立圆仍输出 `CIRCLE`。
- 可用 COM 连接本机正在运行的 AutoCAD (`AutoCAD.Application`) 直接读改图纸、加填充(`AddHatch`/`AddSolid`、`HPDRAWORDER`、`AcCmColor`)。
- DXF R12 文本; R12 不支持中文, `label` 自动转 `\U+XXXX`; 规格按 `utf-8-sig` 读。
- 工艺依据(阴影/厚径比/补偿/材料)见 [references/design-rules.md](./references/design-rules.md)。
