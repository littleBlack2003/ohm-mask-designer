# 歐姆掩模設計器 瀏覽器版 0.9.5

[English](使用说明.en.md) | [简体中文](使用说明.md) | [繁體中文](使用说明.zh-Hant.md)

> 本頁為**台灣用語**版；通用繁體見 [使用说明.zh-Hant.md](使用说明.zh-Hant.md)。

用於離線設計蒸鍍掩模總成（掩模片＋骨架）。軟體內建「預設 25mm 基底」範例專案，其中包含已確認的幾何、圖案、ITO 和打標設定。

頂部工作區依次為「骨架」「單片圖案」「掩模片」「打標」「總成預覽」和「mask」。每頁只顯示與目前任務有關的工具：單片圖案頁編輯圖案開口和 ITO 區域；打標頁只編輯文字；總成預覽為唯讀檢視。骨架頁右側可直接設定外框、把手、總曠量和基板定位開口陣列。複雜外形、多把手或自訂定位開口可從同一頁進入「完整設定」編輯。

## GitHub Pages 純網頁版

點選 `https://littleblack2003.github.io/ohm-mask-designer/` 即可使用，無需安裝 Python。網頁版透過 Pyodide 在瀏覽器內執行與桌面版相同的 Python/Shapely 幾何和加工匯出程式碼；首次開啟需要連網載入計算執行環境及中文向量字型，之後瀏覽器快取可縮短載入時間。

網頁版專案儲存在目前瀏覽器的本機儲存空間中，不會自動上傳到伺服器。清除瀏覽器資料會刪除這些專案，因此應定期使用「匯出 JSON」備份。生成的 DXF、SVG、CSV、報告和 ZIP 透過頁面中的檔案連結下載到本機。

## 啟動

免安裝包：完整解壓縮，按兩下「歐姆掩模設計器.exe」。程式內建 Python 及計算相依套件，自動開啟預設瀏覽器，無需安裝 Python 或 AutoCAD。請保持 exe 與 `_internal` 資料夾一起，不要單獨複製 exe。瀏覽器網址為 `http://127.0.0.1:8765/`，僅本機可存取，無需連網。

在目前工作區使用原始碼版本時，仍可按兩下「啟動設計器.cmd」。原始碼版本使用本機 Python 環境。免安裝版與已執行的同版本工作台共用現有本機服務，不會額外啟動一份。

關閉頁面後，本機服務仍可繼續儲存工作台狀態。要結束服務，在「專案清單」中點選「儲存並結束本機工作台」。再次按兩下啟動程式即可重新使用。

## 專案管理

- **新建**：沿用目前板件參數並清空圖案、ITO 和打標，建立後自動開啟板件尺寸設定，便於從頭設定下一款掩模。
- **複製另存**：複製完整目前專案，包括幾何、三個圖層及不確定度設定。
- **專案清單**：開啟已有專案，也可匯入完整專案 JSON；切換前會儲存目前專案。同名專案不會被覆蓋。
- **板件尺寸**：按「基本資訊、基板、骨架、定位開口與圖案陣列、掩模片、測試 mask、高級設定」分頁編輯。骨架頁包含主體、把手、邊/角取片缺口和可選安裝孔；掩模片可跟隨骨架外形（含把手），也可設為獨立矩形或圓形；預設定位開口保持直角。
- **高級幾何設定 JSON**：用於多個把手、多個缺口、自訂陣列位置或兩片不同的安裝孔等設定；圖案、ITO 和文字由各自圖層編輯。

每個專案使用獨立檔案和加工目錄，瀏覽器草稿按專案隔離。編輯圖案後自動儲存到專案檔案，也可手動儲存。無效輸入會顯示待儲存或幾何錯誤，修正後再儲存和匯出。

目前工作區的新專案位於「掩模項目」目錄；免安裝版的新專案預設位於使用者目錄下的 `Documents/歐姆掩模設計器/掩模項目`。專案清單顯示實際路徑。原專案繼續使用原有專案目錄。

## 繪圖與分析

圖案開口支援矩形、圓形、長槽和多邊形，可拖曳、精確輸入尺寸、複製、格內陣列、置中和復原。左側將「選擇、平移畫布」放在操作區，將幾何形狀放在繪圖區，目前頁面不適用的工具會自動隱藏。總成預覽分別顯示基板定位開口、掩模片及骨架外形，並隨板件尺寸和陣列變化。掩模片過小、未覆蓋全部定位開口時會阻止儲存和加工匯出。

每個圖案開口都可在右側「區域用途」中標記為「活性區域」「公共電極區域」或「未標記」。Shift 點選或全選多個開口後可批次設定；單格畫布用 A/C 區分活性區域和公共電極區域，開口原有顏色保持不變。區域標記會隨專案 JSON 儲存，並寫入開孔統計、面積表和 CSV，但不改變任何加工切割輪廓。

畫布自動符合視窗。單片圖案使用基片內部網格，間距可在左側設定。骨架、掩模片、打標、總成預覽和 mask 的 10 mm 工程網格、X/Y 中心軸及座標數字預設一起隱藏，可用畫布右下角「網格」按鈕統一開關。開啟後工程網格繪製在板件、開口、圖案和打標之上。較大外形的數軸刻度會自動放大以保持清晰。各工作區均支援滾輪縮放（以滑鼠位置為中心）、「平移畫布」工具、滑鼠中鍵或按住空白鍵拖曳。「符合視窗」恢復完整顯示；這些操作不改變加工座標。

Shift 點選可多選，「全選」只選目前圖層。多個物件或一個多邊形選取後，右側可設定整體中心 X/Y，或輸入 ΔX/ΔY 並套用整體平移，保持物件相互間距；「選取圖案置中」將所選外包框中心移至座標原點。畫布取得焦點後，方向鍵按吸附步長移動選取物件，Shift 方向鍵移動十倍步長。位置調整會自動儲存並支援復原。

ITO 有效區域是獨立參考圖層，不參與蒸鍍掩模切割。只有標記為「活性區域」的開口計算有效面積，有效面積為該開口與 ITO 區域聯集的交集；公共電極區域和未標記開口不計算。開孔統計仍包含所有圖案開口，並區分定位開口及安裝孔；取片缺口已合併，不另計孔。

生成加工檔案時，只要專案同時存在活性區域和 ITO 有效區域，軟體會自動增加一張測試遮光掩模切割 DXF。其外形預設與基板外形相同。程式先以「活性區域開口 ∩ ITO 有效區域」得到活性有效區域，再將每個通光孔的邊長預設縮小到 80%，寬、高吸附到最近 0.1 mm。生成前會驗證通光孔嚴格位於活性有效區域內；公共電極和未標記開口不會成為通光孔。測試掩模使用獨立幾何驗證報告，驗證失敗時保留蒸鍍總成檔案並輸出生成說明。

「板件尺寸」視窗可直接設定測試 mask 的生成開關、通光孔邊長比例、尺寸吸附和外框邊緣餘量。高級幾何設定中對應的 `test_mask` 欄位為 `enabled`、`aperture_scale`、`size_snap_mm`、`edge_margin_mm` 和可選的 `outline`。省略時預設自動生成、外形同基板、邊長比例 0.8、吸附 0.1 mm，邊緣餘量沿用專案最小筋寬要求。

雷射打標文字在全板座標編輯，支援內容、字高、旋轉、移動以及骨架/掩模片/兩片選擇，使用 `LASER_MARK` 獨立向量圖層。中文打標使用系統微軟雅黑字型。

面積不確定度按獨立輸入量的一階解析公式計算：`u(A)=√Σ[(∂A/∂qᵢ)u(qᵢ)]²`，`U=2u`。預設圖案尺寸公差 ±0.01 mm，以矩形分布換算為 a/√3；可修改 ITO 尺寸和相對定位誤差。僅報告每個活性區域，不加總，不使用蒙地卡羅。邊界重合或不合用的複雜裁切會註明估計方法或暫不提供 u，詳見《有效面積計算說明》。

幾何驗證採用整塊掩模片和骨架的真實邊界，檢查越界、加工輪廓衝突和實際筋寬；不把單格的虛擬定位邊界當作薄片切割邊界。

## 加工匯出

點選「生成加工檔案」，驗證通過後同時生成：

- 掩模片、骨架的切割 DXF；只包含加工輪廓。
- 存在打標時，各目標片的獨立雷射打標 DXF。
- 裝配參考及兩片含 ITO 參考的 DXF。
- 裝配 SVG 預覽、幾何驗證報告、加工說明、完整設計 JSON。
- 已標記活性區域且定義 ITO 時的逐活性區域面積不確定度 CSV（或不可計算的說明）。
- 自動派生的測試遮光掩模切割 DXF 及獨立驗證報告（外形預設同基板）。
- 只包含本次生成結果的 ZIP 加工檔案包。

DXF 單位 mm、比例 1:1，為設計名義尺寸。割縫補償由加工方設定，材料和厚度在下單時選擇。ITO 與基片參考圖層不切割；文字按打標處理，不得切穿。幾何錯誤會阻止匯出，警告需結合具體製程覆核。
