# Ohm Mask Designer — Browser Edition 0.9.5

[English](使用说明.en.md) | [简体中文](使用说明.md) | [繁體中文](使用说明.zh-Hant.md)

For offline design of evaporation mask assemblies (mask foil + frame). The app ships with a built-in "Default 25 mm substrate" example project containing confirmed geometry, pattern, ITO, and marking settings.

The top workspaces are, in order, "Frame", "Single-cell pattern", "Mask foil", "Marking", "Assembly preview", and "mask". Each page shows only the tools relevant to the current task: the single-cell pattern page edits pattern apertures and the ITO area; the marking page edits text only; the assembly preview is read-only. On the Frame page you can set the outer outline, handle, total clearance, and substrate positioning-opening array on the right. Complex outlines, multiple handles, or custom positioning openings can be edited via "Full settings" from the same page.

## GitHub Pages web edition

Visit `https://littleblack2003.github.io/ohm-mask-designer/` — no Python install required. The web edition runs the same Python/Shapely geometry and manufacturing-export code as the desktop app inside the browser via Pyodide; the first launch needs an internet connection to load the compute runtime and the Chinese vector font, after which the browser cache shortens loading.

Projects in the web edition are stored in the current browser's local storage and are never uploaded to a server. Clearing browser data deletes them, so back up regularly with "Export JSON". The generated DXF, SVG, CSV, reports, and ZIP are downloaded to your machine via the file links on the page.

## Launch

Portable package: unzip it fully and double-click "欧姆掩模设计器.exe". The program bundles Python and the compute dependencies, opens your default browser automatically, and needs no Python or AutoCAD. Keep the exe together with the `_internal` folder — do not copy the exe alone. The browser address is `http://127.0.0.1:8765/`, accessible only from this machine and needing no network.

When using the source version in the current workspace, you can still double-click "启动设计器.cmd". The source version uses your local Python environment. The portable build shares the existing local service with an already-running workbench of the same version and will not start a second one.

After closing the page, the local service can keep saving the workbench state. To end the service, click "Save and shut down the local workbench" in "Project list". Double-click the launcher again to use it again.

## Project management

- **New**: reuse the current panel dimensions and clear the pattern, ITO, and marking; after creation it opens the panel size settings so you can configure the next mask from scratch.
- **Save a copy as**: copy the complete current project, including geometry, the three layers, and uncertainty settings.
- **Project list**: open an existing project or import a full project JSON; the current project is saved before switching. A project with the same name is not overwritten.
- **Panel sizes**: edited as tabs "Basic info, Substrate, Frame, Positioning openings & pattern array, Mask foil, Test mask, Advanced". The Frame page includes the body, handle, edge/corner pick notches, and optional mounting holes; the mask foil can follow the frame outline (including the handle) or be an independent rectangle or circle; positioning openings are right-angled by default.
- **Advanced geometry JSON**: for configurations such as multiple handles, multiple notches, custom array positions, or different mounting holes on the two pieces; pattern, ITO, and text are edited in their own layers.

Each project uses its own file and manufacturing directory, and the browser draft is isolated per project. The pattern is auto-saved to the project file after editing, and you can also save manually. Invalid input shows a pending-save or geometry error; fix it before saving and exporting.

New projects in the current workspace live in the "掩模项目" directory; for the portable build they default to `Documents/欧姆掩模设计器/掩模项目` under your user directory. The project list shows the actual path. Existing projects keep using their original project directory.

## Drawing and analysis

Pattern apertures support rectangle, circle, slot, and polygon; you can drag, type exact sizes, copy, array within a cell, center, and undo. On the left, "select, pan canvas" are in the operation area and the geometric shapes in the drawing area; tools not applicable to the current page are hidden. The assembly preview shows the substrate positioning openings, the mask foil, and the frame outline separately, updating with the panel dimensions and array. If the mask foil is too small or does not cover all positioning openings, saving and manufacturing export are blocked.

Each pattern aperture can be tagged on the right as "Active region", "Common electrode region", or "Untagged". Shift-click or select all to set several at once; on the single-cell canvas, A/C distinguishes active from common electrode regions while the aperture's own color is unchanged. Region tags are saved in the project JSON and written to the opening statistics, area table, and CSV, but they do not change any manufacturing cutting contour.

The canvas fits the window automatically. The single-cell pattern uses the substrate's internal grid, whose spacing is set on the left. For Frame, Mask foil, Marking, Assembly preview, and mask, the 10 mm engineering grid, X/Y center axes, and coordinate numbers are hidden together by default and can be toggled with the "Grid" button at the bottom-right of the canvas. When enabled, the engineering grid is drawn above the panels, openings, pattern, and marking. Axis ticks for larger outlines auto-scale to stay legible. Every workspace supports wheel zoom (centered on the mouse), the "Pan canvas" tool, the middle mouse button, or holding Space to drag. "Fit to window" restores the full view; these operations do not change the manufacturing coordinates.

Shift-click to multi-select; "Select all" selects only the current layer. With several objects or one polygon selected, you can set the overall center X/Y on the right, or enter ΔX/ΔY and apply a whole-selection shift while keeping the objects' relative spacing; "Center selected pattern" moves the selection's bounding-box center to the origin. With the canvas focused, the arrow keys move the selection by the snap step and Shift+arrow by ten times the step. Position changes are auto-saved and undoable.

The ITO effective area is an independent reference layer that does not participate in evaporation-mask cutting. Only openings tagged as "Active region" have their effective area computed; the effective area is the intersection of that opening with the unioned ITO area; common-electrode and untagged openings are not computed. Opening statistics still include all pattern apertures and distinguish positioning openings and mounting holes; pick notches are merged and not counted separately.

When generating manufacturing files, if the project has both active regions and an ITO effective area, the app automatically adds a test light-blocking mask cutting DXF. Its outline is the substrate outline by default. The program first derives the active effective area as "active-region opening ∩ ITO effective area", then shrinks each through-hole's edge length to 80% by default and snaps width and height to the nearest 0.1 mm. Before generating, it validates that the through-holes lie strictly inside the active effective area; common-electrode and untagged openings never become through-holes. The test mask uses its own geometry validation report; if validation fails, the evaporation-assembly files are kept and a generation note is output.

The "Panel sizes" window sets the test mask generation toggle, through-hole edge-length ratio, size snap, and outline edge margin directly. In the advanced geometry config the corresponding `test_mask` fields are `enabled`, `aperture_scale`, `size_snap_mm`, `edge_margin_mm`, and an optional `outline`. When omitted, the defaults are: auto-generate, outline same as substrate, edge-length ratio 0.8, snap 0.1 mm, and edge margin following the project's minimum web requirement.

Laser-marking text is edited in whole-panel coordinates and supports content, text height, rotation, movement, and Frame/Mask foil/Both targets, using the independent `LASER_MARK` vector layer. Chinese marking uses the system Microsoft YaHei font.

Area uncertainty is computed with the first-order analytical formula for independent inputs: `u(A)=√Σ[(∂A/∂qᵢ)u(qᵢ)]²`, `U=2u`. The default pattern-size tolerance is ±0.01 mm, converted from a rectangular distribution to a/√3; the ITO size and relative positioning errors are adjustable. Only each active region is reported — no summing, no Monte Carlo. Boundary-coincident or otherwise inapplicable complex cuts note the estimation method or omit u for now; see "Effective area calculation notes".

Geometry validation uses the real boundaries of the whole mask foil and frame, checking out-of-bounds, manufacturing-contour conflicts, and actual web width; it does not treat the single cell's virtual positioning boundary as the foil's cutting boundary.

## Manufacturing export

Click "Generate manufacturing files"; after validation passes, the app produces:

- Cutting DXF for the mask foil and frame; containing only manufacturing contours.
- Independent laser-marking DXF for each target piece when marking exists.
- Assembly reference and DXF of both pieces with ITO reference.
- Assembly SVG preview, geometry validation report, manufacturing notes, and complete design JSON.
- A per-active-region area-uncertainty CSV (or a note explaining why it cannot be computed) when active regions are tagged and ITO is defined.
- The auto-derived test light-blocking mask cutting DXF and its independent validation report (outline same as substrate by default).
- A ZIP manufacturing package containing only the results of this run.

DXF is in mm at 1:1 scale, as design nominal dimensions. Kerf compensation is set by the manufacturer, and material and thickness are chosen when ordering. The ITO and substrate reference layers are not cut; text is treated as marking and must not be cut through. Geometry errors block export; warnings should be reviewed against the actual process.
