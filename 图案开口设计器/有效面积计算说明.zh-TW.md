# 開孔統計與單 Pixel 有效面積不確定度

[English](有效面积计算说明.en.md) | [简体中文](有效面积计算说明.md) | [繁體中文](有效面积计算说明.zh-Hant.md)

> 本頁為**台灣用語**版；通用繁體見 [有效面积计算说明.zh-Hant.md](有效面积计算说明.zh-Hant.md)。

右側「開孔統計 / 活性區域面積」統計單格圖案開口、全板圖案開口、兩片安裝孔和骨架定位開口。ITO 參考區域、打標文字和已合併的取片缺口不另計孔。圖案開口須標記為活性區域、公共電極區域或未標記。

「活性區域面積與不確定度…」只計算標記為活性區域的開口，公共電極和未標記開口不進入結果。每個活性區域獨立報告，不加總面積或不確定度。有效面積定義為該活性區域開口與 ITO 區域聯集的交集；未定義 ITO 時不假定整個基片均有效。更改設計、用途標記或誤差後，舊結果失效，需重新計算。

## 誤差輸入與傳播公式

預設圖案尺寸公差 ±0.01 mm，可修改。矩形分布公差半寬為 a 時，輸入標準不確定度 u(q)=a/√3。選擇「標準不確定度 · 1σ」時，直接填寫 u(q)，不再換算；切換方式不自動轉換數值。

採用獨立輸入量的一階誤差傳播公式：

u(A)=√[Σ(∂A/∂qᵢ × u(qᵢ))²]；U=2u(A)，k=2。

不使用隨機取樣，不報告取樣均值或分位區間。U=2u 不聲明精確 95% 覆蓋。名義面積為 0 時，相對不確定度無定義。

## 面積和解析靈敏度

- 完全包含在 ITO 中的矩形：A=wh；∂A/∂w=h，∂A/∂h=w。
- 完全包含的圓：A=πd²/4；∂A/∂d=πd/2。
- 完全包含的長槽：A=w(l−w)+πw²/4；∂A/∂l=w，∂A/∂w=l+(π/2−2)w。
- 同向矩形裁切（支援共同旋轉及相差 90°）：在 ITO 局部座標中，Lx=max(0,min(x右,xITO右)−max(x左,xITO左))，Ly 同理，A=LxLy。對目前有效的 min/max 分支求解析導數，再按 ∂A/∂q=Ly·∂Lx/∂q+Lx·∂Ly/∂q 傳播。

w/h 是開口完整寬高，W/H 是 ITO 完整寬高，d 是直徑，l 是槽總長。X/Y 相對定位誤差表示開口與 ITO 之間的平移，公式將它們轉換到 ITO 局部座標。輸入尺寸誤差不是單邊誤差。輸入量彼此獨立，旋轉角固定。

邊界恰好重合時面積函數不可微，採用左右導數絕對值較大者作保守線性估計，並在對應 Pixel 的說明中標記。該估計不等於完整非線性面積分布的標準差。若非零間隙小於誤差可能導致的邊界移動、使裁切分支可能改變，則不報告 u，提示一階公式不適用；直接輸入標準不確定度時，用 3u 作此局部適用性檢查。

複雜裁切暫不提供解析不確定度，僅顯示名義面積和說明。支援同向矩形裁切以及有足夠邊界餘量的完全包含開口。多邊形未定義寬高尺寸誤差模型，非零對應尺寸誤差時不報告 u。曲線交集名義面積用高密度折線近似，完整圓及長槽面積使用精確公式。

## 範圍與匯出

ITO 尺寸及相對定位誤差預設 0，表示未計入，不代表已測得為 0。未納入共享加工尺寸偏差、基片誤差、變形、蒸鍍陰影和角度誤差。

CSV 包含開孔計數、誤差模型、輸入參數、每個活性區域的名義面積、u、U、相對 u、計算公式及說明，不含面積合計。參數隨瀏覽器草稿、專案草稿和設計 JSON 儲存，不改變蒸鍍掩模輪廓。
